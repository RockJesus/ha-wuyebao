# 物业宝 Home Assistant 集成（wuyebao）

[![HACS Default](https://img.shields.io/badge/HACS-Default-orange.svg)](https://hacs.xyz/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Home Assistant 自定义集成（集成域名 `wuyebao`），用于连接物业宝 App，实现门禁控制、实时监控、访客管理等功能。

> 仓库：https://github.com/RockJesus/ha-wuyebao

## 功能特性

- ✅ 用户名密码登录（client_id 与 App 对齐）
- ✅ Token 自动刷新（长期有效，突破7天限制）
- ✅ 门禁设备列表自动发现（**返回小区全部门**：小区门 + 各楼栋单元门，按楼栋/单元正确命名；实体按稳定 gate id 注册，更新不会删除已有门）
- ✅ 门锁实体（每个门禁一个实体，支持 SIP 开门）
- ✅ **来访自动开门**开关（每个门独立，开启后检测到该门访客呼叫立即自动开门，状态持久化）
- ✅ 最近访客摄像头实体（每个门一个，显示最后一次访客按门铃的抓拍照片，附访客时间属性）
- ✅ **实时视频流**（内置 RTSP 服务器，支持 go2rtc / ffmpeg 拉流观看监控，小区门/单元门均可实时观看；**自动续流**——画面中断自动重建会话）
- ✅ 实时监控摄像头属性直接显示 RTSP 地址（`rtsp://<haos主机ip>:8556/<gate-id>`）
- ✅ 传感器：用户名、小区信息、门禁流媒体地址（每门）、gate-id（每门）
- ✅ 主站实体：访客开门码（显示密码+起止时间）、生成访客码按钮、人脸信息（图片实体，直接显示人脸照片）、小区公告、门禁报警、报修记录、呼叫记录（图片实体，直接显示最近呼叫抓拍图）
- ✅ **呼叫电梯**（每个单元门一个按钮，SIP call_elevator）
- ✅ **户户通呼叫**（主站按钮，SIP INVITE 呼叫室内机，可看室内机画面）
- ❌ 扫码开门二维码（App 本地算法生成，逆向中）

## 安装

### 方法一：HACS 安装（推荐）

#### 通过自定义存储库添加（首次使用）

1. 确保已安装 [HACS](https://hacs.xyz/)（若未安装，请先在 HACS 官网按引导完成安装）
2. 打开 Home Assistant，进入 **设置** > **设备与服务** > **HACS**（或侧边栏 **HACS**）
3. 点击右上角 **三个点菜单（⋮）**，选择 **自定义存储库**（Custom repositories）
4. 在弹出的输入框中填写：
   - **存储库地址**（Repository）：`https://github.com/RockJesus/ha-wuyebao`
   - **类别**（Category）：选择 **集成**（Integration）
   - 点击 **添加**（Add）
5. 底部会提示"这个存储库已添加到 HACS"，回到 HACS 首页
6. 点击 **集成**（Integrations）标签，点击右下角 **+ 浏览并添加存储库**（Explore & add repositories）
7. 搜索 **物业宝** 或 **wuyebao**，点击进入
8. 点击 **下载**（Download），等待下载完成
9. 按提示 **重启 Home Assistant**

#### 后续更新

- HACS 检测到新版本后，集成卡片会出现 **更新**（Update）按钮，点击更新并重启 Home Assistant 即可

### 方法二：手动安装

1. 到 Releases 页面下载最新版安装包（`wuyebao-ha-vX.Y.Z.zip`）：https://github.com/RockJesus/ha-wuyebao/releases
2. 解压后得到 `custom_components/wuyebao/` 文件夹
3. 将其复制到 Home Assistant 的 `custom_components/` 目录（覆盖旧版本）
4. 重启 Home Assistant

## 配置

1. 在 Home Assistant 中，进入 **设置** > **设备与服务**
2. 点击 **添加集成**
3. 搜索 "物业宝"
4. 输入手机号和密码
5. 点击提交（房间号由登录后的绑定编码**自动获取**，无需手动填写，呼叫电梯/户户通开箱即用）

## 实体说明

### 门锁实体

每个门禁设备会自动创建一个门锁实体：

- **名称**：根据设备别名/楼栋单元自动命名（如"小区门"、"单元门"）
- **状态**：始终显示锁定，解锁后 10 秒自动恢复锁定
- **解锁**：调用 `lock.unlock` 服务发送开门指令

**属性**：
- `device_id` - 设备 ID
- `device_type` - 设备类型（outdoor/wall）
- `unlock_password` - 开门密码
- `sip_target` - SIP 目标地址

### 开关实体

- **来访自动开门**（每门一个）：开启后，检测到该门有新的访客呼叫时立即自动开门；开关状态持久化保存，重启后保持

### 传感器实体

- **用户名** - 当前登录账号
- **小区** - 所在小区名称
- **门禁流媒体地址**（每门一个）：`rtsp://<haos主机ip>:8556/<gate-id>`，供 go2rtc / ffmpeg 直接复制使用
- **gate-id**（每门一个）：该门的门禁设备 ID
- **访客开门码**（主站）：值显示最新有效访客开门密码，属性含起止时间（格式化显示）与有效状态
- **小区公告**（主站）：首页轮播/公告内容数与图片链接
- **门禁报警**（主站）：报警记录数与最新报警
- **报修记录**（主站）：未完成报修工单数

### 图片实体（image）

- **人脸信息**（主站）：直接显示最近的人脸抓拍照片（自动刷新，URL 变化即更新）
- **呼叫记录**（主站）：直接显示最近一次访客呼叫的抓拍照片（自动刷新，URL 变化即更新）

### 按钮实体

- **生成访客码**（主站）：点击后为当前业主生成 6 位访客开门密码（默认 1 小时有效，与 App 一致），生成后通过系统通知显示密码
- **呼叫电梯**（每个单元门一个）：点击后通过 SIP MESSAGE 呼叫该单元的电梯（`call_elevator`，目标为单元门 OD 地址，呼叫目标楼层为配置的房间号），电梯到达后自动停靠
- **户户通呼叫**（主站）：点击后通过 SIP INVITE 呼叫**自家室内机**（RM 地址，由房间号推导楼层/房号），建立音视频会话后可在 `rtsp://<haos主机ip>:8556/rm-<房间号>` 观看室内机画面（配合 go2rtc 可转 WebRTC）

### 摄像头实体

每个带摄像头的门禁设备（小区门、单元门）会自动创建两个摄像头实体：

**最近访客摄像头**
- **名称**：根据设备别名/楼栋单元自动命名（如"小区门最近访客"、"单元门最近访客"）
- **图像**：显示该门禁设备**最后一次访客按门铃后的抓拍照片**（呼叫记录严格按设备匹配，不会串图）
- **属性**：`最近访客时间`（该抓拍记录的生成时间）、`gate_id`、`device_number`
- **挂载**：与门锁实体挂载在同一设备下

**实时监控摄像头（实时视频流）**
- **名称**：如"小区门实时监控"、"单元门实时监控"
- **机制**：集成内置 RTSP 服务器，通过 SIP INVITE 建立监控会话，H264 RTP 流经内置 RTSP 服务器转发（`rtsp://<haos主机ip>:8556/<gate-id>`）
- **go2rtc 集成**：在 go2rtc 配置中添加摄像头属性中的 `rtsp_url` 源即可转 WebRTC 实时观看
- **自动重试**：无媒体时自动挂断重试（最多 5 次，退避 4/6/10/15s），设备忙（486）时自动等待设备释放会话后重拨
- **自动续流**：门口机约 30s 后停止推流导致画面冻结时，看门狗自动检测静默并重建监控会话，持续观看无需手动操作
- **NAT 打洞**：自动复制 App 的 "probing data" + RTCP 打洞机制打通媒体通道（0.5s 持续打洞）

**工作原理**：
1. 登录后获取业主信息（含室内机 `bindingCode`）
2. 调用呼叫记录接口获取该室内机收到的门口机呼叫记录
3. 按设备严格匹配呼叫记录中的 `imageUrl`（阿里云 OSS 抓拍图）
4. 摄像头实体展示匹配的最新抓拍图
5. 实时视频流：RTSP 客户端拉流时，集成通过 SIP REGISTER → INVITE 建立与门口机的监控会话，收到 H264 RTP 后转发给 RTSP 客户端

**说明**：
- 单元门（outdoor）有呼叫记录，最近访客/实时监控均可正常显示
- 小区门（wall）如无呼叫/报警记录，摄像头显示"不可用"（不会错误显示其他门的图像）
- 可在物业宝 App 中按铃呼叫单元门，生成新的抓拍记录

**属性**：
- `gate_id` - 门禁设备 ID
- `device_number` - 设备号（a/b=小区门、数字=单元门）
- `rtsp_url` - RTSP 实时流地址（实时监控摄像头）
- `最近访客时间` - 最近访客抓拍记录时间（最近访客摄像头）

## API 说明

本集成基于物业宝 App 抓包分析，主要接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/client/anon/token` | POST | 登录获取 Token（请求头需带 App 的 client_id） |
| `/api/client/anon/refresh_token` | GET | 刷新 Token |
| `/api/client/anon/client_token` | GET | 获取 SIP Token |
| `/api/device/grant/gates` | GET | 获取门禁列表 |
| `/api/owner/anon/owners/community` | GET | 获取业主信息 |
| `/api/owner/grant/owners` | GET | 获取业主详情（含室内机 bindingCode、unitId） |
| `/api/call/{page}/{size}/grant/calls` | GET | 获取呼叫记录（含门口机抓拍图） |
| `/api/repair/repairs` | GET | 获取报修记录 |
| `/api/invitevisitor/grant/invitevisitors` | GET | 获取访客开门码列表 |
| `/api/invitevisitor/grant` | POST | 生成访客开门码 |
| `/api/face/grant/faceinfo` | GET | 获取人脸信息 |
| `/api/content/anon/classify/contents` | GET | 获取小区公告/轮播 |
| `/api/alarm/grant/alarms` | GET | 获取门禁报警记录 |

  - 平时无任何 RTSP 客户端连接时完全静默，不发任何 SIP/API 请求
